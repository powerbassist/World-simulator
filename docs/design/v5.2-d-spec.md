# V5.2 d — the voice: speakers, the event re-tune, front pages, sound

The tier's d ([[v5]], "d — the voice"): events given speakers and re-tuned to 0
dominated pairs, with `events_probe`'s E2/E3 failing the run; designed voices,
music and effects through a `tools/` pipeline, each file's provenance in
`REUSE.toml`; English now, French later. Plus the author's d+ (2026-10-25,
verbatim): "oui, des popup de titres de journaux qui marquent des events
importants", placed "Dans V5.2, bloc d".

Owners, from the V5.2 brief: Content writes the speakers' lines, the headline
templates and the re-tuned numbers (GLM drafts the bulk); Systems wires the
probe gates, the speaker resolution and the front-page trigger; Interface builds
the card and plays the sound; the sound pipeline is a `tools/` script.

Labels: **MEASURED** (a cited line, a probe table or a source), **INFERRED**
(read from the code or derived, not run), **OPINION** (the designer's call).
Probe figures are from `events_probe` on #150 @ `6115474f` (the 102 events of
main plus the nine exposures; log in the Gameplay scratchpad, "ev150.log").

## 2. The re-tune: three rules, in order, each judged by the probe

The order matters because each rule can undo the one before.

**Rule 1, E2 first: widen the trade, not the default, to a target set by
severity.** For an event whose spread misses its target, scale every
non-default answer's `bloc_offset` about the default's: offset′(c, b) =
default(b) + k × (offset(c, b) − default(b)), with k = target / spread. The
targets are **3.2 for severity 1, 4.0 for severity 2 and 5.0 for severity 3**
(OPINION). A critical event should divide the country more than a minor one,
and a single target would put 93 events at exactly one value, where E2 then
says nothing (GLM's point, kept).
- The default does not move, so `event_lint`'s ±0.008 mean band on it holds.
- The comparisons between answers keep their sign on the linear axes
  (approval, `society.corruption` unscaled), so E3 mostly survives. The
  worst-bloc axis is not linear and is re-read.
- An event over 5.8 scales down the same way, with k = 5.6 / spread.
- **Why 3.2 at the bottom:** the floor plus the margin the exposure events
  needed on 2026-10-25. Every target leaves room under the 5.8 ceiling for
  Rule 2's edits.

**Rule 2, E3 next: give each dominated answer a lead it can be chosen for.**
For each pair where i dominates j, j gains a lead over i by more than twice
E3's tolerance on one axis, by changing j alone:
- Prefer the worst-bloc axis or approval. Move j's offsets toward the blocs
  its fiction speaks to, as the affairs' accountable answer was on 2026-10-25
  (#150).
- A toothless default gains a cost on one axis, so the deadline has teeth.
- Content judges with `events_probe` E3, never with the arithmetic alone.

**Rule 3, E1b last: balance the book per bloc.** A career of defaults (or of
answering well) must not drive any bloc onto the clamp.
- The book-level check is the sum, over the events a run delivers, of each
  bloc's default offsets, and of its answer-well offsets.
- Where a bloc saturates, Content trims that bloc **by the same amount in
  every answer of an event**, the default included, in the events that feed it
  most. A shift common to all answers moves no spread (E2) and no comparison
  (E3), which is the `on_arrival` argument again. Trimming the default alone
  would move Rule 1's pivot and undo it (GLM, kept).
- Keep each default inside `event_lint`'s ±0.008 mean. Where one bloc's trim
  would break it, offset it with an opposite trim on another bloc of the same
  event, sized by the bloc sizes, so the mean stays put.
- **Judge:** E1b on every regime, both paths.

**The loop.** After each rule, Content runs the whole probe (E2, E3 and E1b),
not only that rule's gate, because each rule can undo another. At most three
rounds; an event still failing after three goes to the parent with its rows.

**Systems wires the gates.** `events_probe` records a band failure, so the run
exits non-zero, when:
- any event's E2 spread falls outside [3.0, 5.8];
- E3 counts any dominated pair;
- E3 counts any toothless default.

E1b already fails the run. `tools/run_tests.sh` does not run `events_probe`,
so CI gains it as its own job or shard (Systems' call on where; the runtime is
about 4 minutes, MEASURED on 2026-10-25 under load).

**The re-tune moves the balance table** in every regime, because events fire in
all of them. Systems predicts the re-baseline before the run, and the author
accepts it before the merge, as for every sim change in V5.2.

## 3. Speakers: every event has a face

Today all events are read in a narrator's voice ([[v5-reflection]] T8; "Nobody
speaks", the reflection's diagnosis). In d, each event names **who brings it
to the president**, and the card shows that person's portrait, name and their
line.

**The data.** A new optional field `speaker` on an event, one of:

| `speaker` | Resolves to | Use for |
|---|---|---|
| `{"kind": K}` | of the played nation's people of kind K, never the president, one of the **three with the highest standing**, chosen by a seeded draw over the event and the month (`Cycle.unit`, its own salt, I1) | union_leader for a strike, executive for a plant, regional_figure for a disaster |
| `{"kind": K, "pick": "hostile"}` | of kind K, the lowest rapport (ties: id) | press_owner breaking a scandal |
| `{"kind": K, "pick": "friendly"}` | of kind K, the highest rapport | an ally warning the president |
| `{"office": O}` | the holder of O, `subject_office`'s offices (`head_of_government`, `head_of_state`, `largest_party_leader`) | a cabinet crisis, a party matter |
| `{"evidence_person": true}` | the exposure's evidence row's person | the turned-person exposures: the witness tells it |
| `{"foreign_head": true}` | the counterpart nation's head of government, where the event names a nation | European and foreign events |

- **No id check:** the rule reads kinds, offices and registers, never a nation
  or a person id (rule 1).
- **Resolved at delivery** and stored on the event record, so the face does
  not change while the card waits. A record from before d has no speaker and
  reads as the narrator (absent-ok, no bump).
- **Fallback:** no person qualifies (a vacant office, a kind the nation lacks)
  means the narrator, as today.
- **The line:** each event gains `speaker_line`, a variable-free sentence the
  speaker says, voiced (section 6). The summary stays the card body.
  Content writes both, through `Strings` (an i18n row field).
- **Category guidance (OPINION), for Content's first pass:**
  - industrial: union_leader or executive;
  - commodity: executive;
  - fiscal: head_of_government;
  - unrest: union_leader or activist;
  - disaster: regional_figure;
  - european and foreign: foreign_head;
  - personal: largest_party_leader;
  - scandal: press_owner, hostile;
  - turned exposures: evidence_person.
- **Why the top three by standing:** a few faces recur, so the player learns
  them ("people who talk" applied to the event book), without one person
  voicing every strike of a term (GLM's monoculture point, kept). The draw is
  seeded, so a run is reproducible.
- **An office the president holds is skipped**, for example `head_of_state`
  in France: the speaker is then the head of government, and only if that
  office is the president's too does the narrator speak.
- **No sim effect:** a speaker is presentation. It writes no register, so the
  balance table is unchanged by this part (byte-identical, a check).

## 4. Front pages: the press marks what matters

**What earns a front page (the rule, OPINION):**
- an event the game already calls **major or critical** (severity 2 or 3,
  `events_constants.gd`'s names), which includes every exposure;
- a political moment, each given a severity for the tie-break:
  - an executive or legislative election result (3);
  - a government falling to a censure (3);
  - a dissolution (3);
  - a law carried by Article 49.3 (2);
  - a minister's resignation or a defection, the character acts (2).
- **Why "major or critical":** the author asked for "events importants", and
  the game's own severity names say which those are. The first draft took
  severity 3 and the scandals only, about 5 front pages a term (section 5),
  too few for a third-of-a-term play gate to see more than one or two.

**When:** an event's front page comes when it **resolves**, so the press
reports what the president did (the answer, or the default at the deadline). A
moment's front page comes the month it happens.

**At most one front-page card a month.** The most severe wins; ties go to
the earlier arrival. The others are not lost: they appear on the same card as
one-line "also on the front page" headlines (at most two), from the same
papers. **A front page never holds the
clock:** it is a note-like card, outside the 4 + 6 budget of holds, and it
dismisses itself.

**Which papers, and how slant picks the words.**
- **The tone:** an outlet's tone is its alignment with the government,
  `Media._alignment(outlet.position, ns.coalition_position)`
  (`media.gd:172-176`, [[media-model]]), cut into thirds with the shared 1e-9
  rule: friendly above +0.33, hostile below −0.33, neutral between. No
  outlet's politics is authored beyond its position, so the slant is derived,
  as the media model insists.
- **The two papers:** the card shows the played nation's most friendly and most
  hostile outlet (by alignment), each with its masthead (`name`) and its
  headline. When both fall in the same tone, it shows the two with the
  greatest reach instead. Whether two tones exist depends on the outlets and
  the government's position, not on the card, so a test pins the rule ("two
  tones are shown whenever two exist") and the share is reported, not gated.
- **The words:** each headline is a template keyed by event, answer and tone:
  `headline:<event_id>:<answer_id>:<friendly|neutral|hostile>`. A moment's
  template is keyed by `headline:<moment>:<outcome>:<tone>`.
  - Variables allowed: `{{president}}`, `{{party}}`, `{{nation}}`, mid-sentence.
  - Whole sentences, through `Strings`, English now.
  - GLM drafts; Content curates; the i18n lints decide.
- **Volume (MEASURED count):** 57 of main's 102 events are major or
  critical (45 at severity 2, 12 at severity 3), plus the 10 exposures (the
  nine and the press-favour one, #171), so 67 front-page events. At 2 to 3
  answers and 3 tones that is about 500 headlines, plus about 30 for the
  moments: bulk that GLM drafts and Content curates, against the lints.
- `Media._alignment()` is private today. Systems exposes it, or the one
  reader the card needs, rather than copying it.

**Owners:**
- Systems exposes the trigger: a month's `front_page` entry in the month
  report, ephemeral like a note, not saved.
- Interface builds the card.
- Content writes the templates.

**No sim effect:** the framing machine already moves opinion by outlet
([[media-model]]); the card shows the press, it does not add a second press
effect. Byte-identical balance, a check.

- **Why D7 (OPINION):** a front page should mark the term's turning points,
  not the month's noise. Under 6, the press is absent from a term; over 15, it
  is a ticker. The play gate sees a third of a term, so 2 to 5 front pages.
- **Failure looks like:** a dominated answer left in the book; a card with no
  face on most events; a press that headlines everything or nothing; two
  papers that always agree.

## 6. Sound: voices, music and effects through one `tools/` pipeline

**What is voiced (the tier's rule, [[v5]] "No speech is generated while the
game runs"):**
- variable-free lines only: each event's `speaker_line`, the audience
  greetings and reactions by archetype, and the key beats;
- pre-generated, never at run time;
- on designed voices, one per archetype, never a real person's (the likeness
  ruling).

**Archetypes.** `data/voices/archetypes.json`: id, person kind, sex, age band,
language, the generator's voice id, and the provenance.
- A person gains an optional `voice` field (an archetype id) that Content
  authors. Absent, the person uses their kind's default archetype.
- People carry no sex or age today, so the archetype is chosen by hand from
  the portrait (Content's).

**The pipeline: `tools/voice_pipeline.py`, dev-only.**
- It reads the lines to voice (event `speaker_line`s, archetype line sets)
  and the archetype table.
- It generates each missing clip once.
- It writes `assets/audio/voice/<archetype>/<line_id>.ogg`, loudness-normalised
  to one target so lines sit together.
- It appends one `REUSE.toml` annotation per file: the generator, the plan
  (ElevenLabs Starter, commercial licence bought 2026-10-19), the voice id,
  the date and the source text's id.
- Music (a few loops by tension, and stingers for the front page, a vote's
  result and an election night) and effects go through the same script and
  the same provenance rule.
- **Credits are measured, not assumed:** the script reads the remaining
  allowance before a batch and stops at a floor. The volume is set from that
  measurement, as the tier says.

**Playback** is Interface's. Every clip's text equals the shown text,
English now. A line whose shown text changes needs its clip regenerated, and
the pipeline flags a stale one by the text's hash.

**INFERRED volume for the first batch:** about 111 event lines at about 80
characters each is about 9 000 characters; greetings and reactions at
roughly 12 archetypes × 12 lines × 50 characters is about 7 000. That fits one
month of a Starter allowance before music and effects; the measured
allowance decides.

## 7. The red-team

GLM drafted a red-team; every claim was re-derived. 12 findings:
- **Kept (6):**
  - a single E2 target makes the band measure nothing, hence the severity
    targets;
  - each rule can undo another, hence the loop;
  - trimming defaults moves Rule 1's pivot, hence the common shift;
  - the shift can break the lint mean, hence the opposite trim;
  - the first front-page rule gave too few cards and no tie-break, hence
    "major or critical" and the moments' severities;
  - "highest standing" makes one voice per kind, hence the top three.
- **Changed (2):** the one-a-month cap hid events, so they now appear as
  "also" lines; the two-tone band measured the roster, so it is now a test
  and a reported share.
- **Dropped (4):**
  - "14 a term is wrong": GLM assumed 48-month terms, and France's is 60;
  - "toothless defaults are unaddressed": Rule 2 addresses them;
  - "the headline budget is short": recounted above;
  - "no exploit": agreed.
