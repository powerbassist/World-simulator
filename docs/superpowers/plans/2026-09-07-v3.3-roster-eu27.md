# V3.3 — The roster to Europe (EU-27 + GBR + CHE) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Grow the roster from 10 nations to 29 (EU-27 plus GBR and CHE), each
carrying everything a nation carries today, membership as org-register data,
with the frame gate re-measured at each tranche.

**Architecture:** Content on machines that exist. `tools/import_data.py`
generates the 19 new registers (regions/cities/graph) from datasets already on
disk and already attributed; authored content (nation government blocks,
parties, people, org membership, one playable kit) follows the existing file
contracts exactly; `src/` changes are limited to count pins, one derived UI
constant, one hit-test pre-reject and the save-version bump.

**Tech Stack:** Godot 4.7.1 GDScript (static typing), Python import pipeline,
Eurostat/GISCO/GeoNames/World Bank/Ne sources already cached in `sources/`.

## Global Constraints

- No `if nation_id == …` anywhere new; a nation that behaves differently has a
  field saying so (Rule 1, cardinal). The importer's GBR-only guards are
  dataset-boundary guards that already exist and are not extended.
- One-way dependencies `data -> sim -> ui`; `src/sim/` untouched this block.
- Every new `.gd` gets its `.uid` via `godot --headless --import` before
  `git add`; `project.godot` is never staged; a clean `git status` is the
  alarm.
- Fictionalization per docs/fictionalization.md; real names banned via
  `tools/banned_names.txt`; `tools/check_names.sh` clean at closeout.
- English or French only in user-facing output.
- Bands pre-declared in BALANCE_PLAN.md (done, 2026-09-07, before any run).
- Suite green at every commit; `tools/run_tests.sh` array gains any new test.

## Step-0 findings that correct the row (audited cold, 2026-09-07)

1. **Tranche (a) "no politics" is impossible as labelled, and the loader is
   the reason.** `data_loader.gd` REQUIRES `data/parties/<ID>.json` (4-6
   parties, seat_share summing to 1.0), `data/people/<ID>.json`, and a full
   `government` block for EVERY nation — a nation without them aborts startup.
   So (a) ships complete political content for the 19 (government blocks,
   parties, people, org membership) and defers only the PORTRAITS, the
   PLAYABLE kit and the screenshot pass to (b). The tier's a/b cut survives as
   an ordering inside one plan; the label was wrong about what the loader
   tolerates.
2. **The importer's bounding box excludes Cyprus** (`LON_MAX = 32` vs Cyprus
   at 34.6 E). It widens to 35. The opening fit is LAT-bound (38 deg north
   span unchanged; the probe confirms `_fit_bounds()` is extent-derived), so
   the fit should not move — computed, not assumed, and `CITY_MIN_ZOOM`
   re-derived against the computed number.
3. **`_nation_at_lonlat` has NO bbox pre-reject** and walks the roster
   outlines (4 100 points today, ~11-12k at 29). The V3.1 watch-point is
   real: a per-nation bbox computed at load and checked before the ring loop
   is the fix, with a test.
4. **`data_loader.gd` pins `nations.size() == 10`** — moves to 29.
5. **SAVE_VERSION 32 -> 33** (reason pre-declared in BALANCE_PLAN.md): a
   version-32 save against the 10-nation roster would load as a silent
   10-nation world against 27-member org data; nations are built from the
   save dictionary alone and the gate refuses only version mismatches.
6. **Greece is EL in Eurostat/NUTS and GR in GeoNames** — the UK/GB split
   repeated: `NUTS_COUNTRY["GRC"]="EL"`, `CITY_COUNTRY["GRC"]="GR"`.
7. **EP seats sum to exactly 720** with the real 2024-29 allocations for all
   27 (the existing 8 carry 393; the 19 carry 327).
8. The region graph's sea-link count is DERIVED (components adjacency leaves),
   not authored-then-forced; each new link must be a real crossing in service
   (V2.7's rule), named like the eight that exist.
9. Levels for the 19: all NUTS 2 (the planning unit everywhere in the new
   roster; NUTS 1 there is either single-region or not the real unit). CYP,
   EST, LVA, LTU, MLT are single-region nations on the LUX precedent.
10. No new source enters: every dataset the 19 need is in `sources/` already
    and already has an ATTRIBUTION.md row. Only the row's counts need
    updating (GeoNames subset, portrait count).
